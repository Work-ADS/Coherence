Accessibility

  • El color por sí solo no comunica significado — empareja con texto o icono.
  • Para badges sobre iconos, añade aria-label al contenedor describiendo el conteo ("3 notificaciones nuevas").
  • Un badge es texto estático: no lleva role="status" ni anuncia cambios. Solo el punto suelto (dot) lleva role="img", y necesita ariaLabel.
  • Contraste mínimo 4.5:1 entre texto y fondo en todas las intenciones.

Dos & Don'ts

Do

  • Texto corto (1-2 palabras o números).
  • Empareja intent con el significado: success para "Completado", error para "Fallido".
  • Usa 99+ para contadores grandes en lugar de números reales.

Don't

  • No uses badge para acciones — usa Button o Filter Chip.
  • No mezcles intents arbitrariamente — sé consistente con la semántica.
  • No metas frases largas dentro de un badge.
