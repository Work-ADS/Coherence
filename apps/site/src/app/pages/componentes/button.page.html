Accessibility

  • Usa siempre <button> nativo — nunca <div> ni <a> para acciones.
  • Botones solo-icono requieren ariaLabel descriptivo (e.g. "Eliminar", no "X").
  • En estado loading: renderiza aria-busy="true" y texto "Cargando…" en sr-only.
  • Foco visible con anillo de 2px usando var(--border-focus) — cumple WCAG 2.2.
  • Disabled emite aria-disabled="true" y bloquea la emisión del evento click.
  • Soporta navegación de teclado nativa: Tab enfoca, Enter / Space activan.

Dos & Don'ts

Do

  • Una sola acción primaria por vista — el resto secondary o ghost.
  • Etiqueta describe la acción concreta ("Guardar cambios", no "Aceptar").
  • Usa danger solo para acciones destructivas que el usuario no puede revertir fácilmente.
  • Empareja danger con un Modal de confirmación cuando la acción es irreversible.

Don't

  • No uses danger para acciones constructivas como "Guardar" o "Enviar".
  • No coloques dos primarios en la misma vista — compiten por la atención.
  • No uses una etiqueta genérica ("Aceptar", "OK") que no comunica qué ocurrirá.
  • No emplees un botón para navegación simple entre páginas — usa un enlace.
