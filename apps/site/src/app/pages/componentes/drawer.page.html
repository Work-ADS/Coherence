Accessibility

  • Renderiza con role="dialog" + aria-modal="false": la página de detrás sigue siendo legible.
  • Title se asocia vía aria-labelledby.
  • El foco aterriza en el propio panel (sin anillo) o en initialFocusRef (el cuerpo se desplaza hasta él y el anillo se ve aunque se abriera con el ratón: FocusField), y vuelve a returnFocusRef o al elemento que abrió el drawer.
  • Escape cierra solo la capa de más arriba: un Select o un Tooltip abiertos dentro lo reciben antes; un segundo Escape cierra el drawer.
  • El scroll de la página se bloquea mientras el telón está visible.

Dos & Don'ts

Do

  • Usa drawer cuando el contenido necesita más espacio vertical que un modal.
  • Coloca el botón de acción primario al final del scroll, fijo si el contenido es largo.
  • Mantén el contexto visible — el usuario debe entender qué está editando.

Don't

  • No anides drawers — abre uno cierra el anterior.
  • No uses drawer para confirmaciones cortas — usa Modal.
  • No lo emplees como sidebar permanente — usa Sidebar.
