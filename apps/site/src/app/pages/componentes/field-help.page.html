Components / Field Help
  • Ayuda contextual — una aclaración de dos o tres líneas que no merece una línea fija bajo el campo.
  • Campos con etiqueta larga — el ⓘ sigue a la última palabra de la etiqueta, no se va al borde del campo.
  • Siempre visible — para texto que el usuario debe leer, use hint, no help.
Etiqueta

Accessibility

  • El ⓘ es un botón alcanzable con Tab, con nombre «Más información sobre <etiqueta>» (o helpLabel).
  • El texto de ayuda es la descripción del botón (aria-describedby a un nodo oculto): se lee sin abrir la burbuja.
  • La burbuja se abre al enfocar, al pasar el ratón y al pulsar o tocar. Escape la cierra primero y deja abierto el diálogo o el panel que haya detrás.
  • Pulsar el ⓘ nunca enfoca ni activa el campo, y sigue activo aunque el campo esté deshabilitado.
  • El ⓘ queda fuera del elemento <label>: no forma parte del nombre del campo.

Dos & Don'ts

Do

  • Texto corto y concreto: qué es el dato y de dónde sale.
  • Use hint para lo que debe leerse siempre.

Don't

  • No esconda aquí un requisito obligatorio del formato.
  • No dependa solo del ratón: el texto debe llegar también con teclado y con toque.
