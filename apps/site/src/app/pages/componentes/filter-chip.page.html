Accessibility

  • The pill holds two sibling buttons (the body and the ×): a button never contains a button. The × is named «Quitar filtro de …» or «Borrar …».
  • aria-pressed reflects active/inactive state on each toggle chip; a trigger chip (asTrigger) reports aria-haspopup and aria-expanded instead, and its leading reset never opens the panel.
  • Chips are focusable buttons — Enter/Space toggles the filter.
  • Active state is communicated via both visual change (background + text weight) and ARIA.
  • When a chip opens a dropdown, add aria-haspopup="listbox" and aria-expanded.

Dos & Don'ts

Do

  • Show a chevron when the chip opens a sub-filter dropdown.
  • Allow multiple filters to be active simultaneously.
  • Keep labels short (1–2 words).
  • Update the filtered content immediately on toggle (no submit button).

Don't

  • Don't use for navigation — use tabs or segmented control instead.
  • Don't mix filter chips with status chips in the same row.
  • Don't use more than 6–8 filter chips — group into a filter panel.
  • Don't use color alone to indicate active state — weight + background must both change.
