Accessibility

  • Trigger button has aria-label="Editar [ariaLabel]" for screen readers.
  • Enter commits the edit, Escape cancels — standard keyboard interaction.
  • Input receives focus automatically when edit mode activates.
  • Commit and cancel buttons have descriptive aria-label attributes.

Dos & Don'ts

Do

  • Show a toast confirmation after successful edit.
  • Wrap with afi-tooltip showing the shortcut hint.
  • Trim whitespace before committing.
  • Only emit committed when value actually changes.

Don't

  • Don't use for multi-line text — use a textarea component instead.
  • Don't allow empty commits — validate before emitting.
  • Don't use when the text is not user-editable (use plain text).
