Accessibility

  • Todo input requiere label visible o ariaLabel cuando el label vive fuera del componente.
  • required añade un asterisco visible y emite aria-required="true".
  • error aplica borde rojo, mensaje y aria-invalid="true" — el lector lo anuncia al recibir foco.
  • hint se asocia vía aria-describedby automáticamente.
  • Foco visible con anillo de 2px (--border-focus).
  • disabled bloquea interacción y emite aria-disabled="true"; readonly permite foco y copia.

Dos & Don'ts

Do

  • Etiqueta visible siempre que sea posible — placeholder no es etiqueta.
  • Mensajes de error específicos: describe el problema y cómo corregirlo.
  • Hint para guiar formato esperado ("DD/MM/YYYY", "mínimo 8 caracteres").
  • Empareja con autocomplete para campos comunes (email, name, address).

Don't

  • No uses placeholder como única etiqueta — desaparece al escribir.
  • No muestres errores antes de que el usuario interactúe con el campo.
  • No deshabilites campos sin indicar por qué — añade hint explicativo.
  • No uses type="text" para emails o números — pierdes teclado nativo.
