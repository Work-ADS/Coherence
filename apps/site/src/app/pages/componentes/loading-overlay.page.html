Accessibility

  • Renderiza con role="status" + aria-live="polite" para anunciar el estado de carga.
  • message se anuncia al usuario de lectores de pantalla.
  • El delay (300ms por defecto) evita parpadeos en cargas instantáneas.
  • Spinner respeta prefers-reduced-motion: se sustituye por texto estático.

Dos & Don'ts

Do

  • Empleo el delay (300ms) para evitar flashes en cargas rápidas.
  • Usa line-reveal para refetches en background.
  • Cubre el contenedor relevante, no la página entera.

Don't

  • No abuses del overlay para cargas instantáneas (<100ms).
  • No bloquees toda la página si solo una sección está cargando.
  • No mezcles overlay con skeleton — elige un patrón por contexto.
