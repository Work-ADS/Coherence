Accessibility

  • Renderiza con role="menu" + items con role="menuitem".
  • Trigger usa aria-haspopup="menu" y aria-expanded sincronizado con el estado.
  • Flechas navegan items, Enter activa, Escape cierra.
  • Foco vuelve al trigger al cerrar el menu.
  • Item danger se anuncia con su variante para distinguirlo.

Dos & Don'ts

Do

  • Items con verbos de acción ("Editar", "Eliminar").
  • Coloca el item destructivo al final, con variant danger.
  • Usa kbd dentro de menu items para mostrar shortcuts.

Don't

  • No anides Menu dentro de Menu — la jerarquía se pierde.
  • No uses menu para flujos largos — usa Modal o Drawer.
  • No mezcles items de navegación con items de acción.
