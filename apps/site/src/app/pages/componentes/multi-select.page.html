Components / Multi Select
  • Filtros de un conjunto de datos — tipo de activo, titular, producto: cualquiera de varios.
  • Fila de filtros — shape="pill", o un chip como cierre con #trigger.
  • Select o Multi Select — si los consumidores piden siempre «Todos» como opción, es un Multi Select.
Summary

Accessibility

  • El botón es un combobox con aria-controls y aria-activedescendant; la lista es un listbox multiselección.
  • Flechas, Inicio y Fin recorren filas (también la fila «Todos», las cabeceras de grupo y los enlaces «Seleccionar todo» y «Limpiar»); Intro y Espacio marcan sin cerrar; Escape cierra y devuelve el foco; Tab cierra.
  • La fila «Todos» y las cabeceras de grupo tienen estado marcado, mixto o sin marcar; solo actúan sobre las opciones habilitadas.
  • La marca se dibuja en la fila, no con un checkbox anidado: la fila entera es el control y no añade una segunda parada de Tab.
  • Con un chip como cierre (#trigger) el chip ofrece aria-expanded; su ⊗ inicial limpia el filtro sin abrir el panel.
