Components / Nav Item
  • Sidebar navigation — primary and secondary nav items within a collapsible sidebar.
  • Active state indicator — marks the current page/section with distinct background and text color.
  • Notification badges — numeric or text badges for unread counts or alerts.
  • Collapsed tooltip — when the sidebar is collapsed, shows a tooltip with the full label on hover.
  • Keyboard navigation — supports arrow keys, Home, End within the sidebar context.

Accessibility

  • Renders as native <button> — fully keyboard accessible.
  • Active item marked with aria-current="page".
  • Collapsed state shows tooltip with label on hover/focus for screen readers.
  • Focus ring uses var(--border-focus) at 2px offset.
  • Disabled items have opacity: 0.4 and pointer-events: none.
  • Supports prefers-reduced-motion — transitions disabled.

Dos & Don'ts

Do

  • Use one active nav-item at a time within a sidebar.
  • Keep labels short (1–3 words).
  • Include a leading icon for visual scannability.
  • Use badge for notification counts ("99+" max).

Don't

  • Don't mark multiple items as active simultaneously.
  • Don't use for actions (use Button or Menu Item instead).
  • Don't use long labels that truncate — shorten or use a tooltip.
  • Don't show large badge numbers — cap at 99+.
