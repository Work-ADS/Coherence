Accessibility

  • Native <select> bajo el estilizado — teclado y screen reader son nativos.
  • Space abre el desplegable; flechas navegan; Enter confirma.
  • Label requerido (visible o ariaLabel).
  • Estado error añade aria-invalid="true" y mensaje asociado vía aria-describedby.

Dos & Don'ts

Do

  • Placeholder descriptivo ("Seleccione un país").
  • Ordena opciones por relevancia o alfabéticamente — la más común primero.
  • Para listas largas (15+) considera un searchable select.

Don't

  • No uses select para 2-3 opciones — usa segmented-control o radio-group.
  • No uses select sin label.
  • No incluyas la opción "Seleccione…" dentro de las options — usa placeholder.
