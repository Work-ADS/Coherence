Accessibility

  • Renderiza landmarks semánticos: <header>, <nav>, <main>, <aside>.
  • Skip link al main content desde el top bar.
  • El sidebar cierra automáticamente en mobile cuando se selecciona un item.

Dos & Don'ts

Do

  • Elige workspace para apps productivas con navegación lateral.
  • Usa auth para flujos en los que el chrome distrae.
  • Usa canvas cuando el contenido necesita todo el ancho.

Don't

  • No mezcles tipos de shell en una sesión — confunde al usuario.
  • No anides shells dentro de shells.
  • No personalices el layout dentro del shell — usa Page Header + Card.
