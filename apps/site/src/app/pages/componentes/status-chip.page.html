Accessibility

  • Interactive mode renders aria-haspopup="menu" on the button.
  • Static mode uses role="status" for live announcements.
  • aria-label defaults to the estado label text; override with custom label for more context.
  • Color alone does not convey state — the dot + text label ensure accessibility.
  • Focus ring follows var(--border-focus) standard.

Dos & Don'ts

Do

  • Always show the dot + text label together for colorblind users.
  • Use interactive mode when clicking should open a state-change menu.
  • Use subtle variant in most contexts; solid for high-emphasis callouts.
  • Pair with a dropdown when interactive — never use the chip alone for state changes.

Don't

  • Don't use as a generic tag/label — this component is specifically for workflow states.
  • Don't remove the chevron in interactive mode — it signals clickability.
  • Don't use solid variant in dense table views — it's too heavy visually.
  • Don't cycle states on click without a confirming dropdown.
