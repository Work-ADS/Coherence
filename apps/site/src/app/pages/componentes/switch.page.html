  • Preferencias de aplicación — notificaciones, modo oscuro, autoguardado.
  • Permisos por sección — activar/desactivar acceso a una funcionalidad.
  • Feature flags — toggles visibles para usuarios admin/beta.

State

Accessibility

  • Renderiza role="switch" + aria-checked para que lectores anuncien el estado correcto.
  • Space y Enter activan / desactivan; Tab enfoca.
  • Label asociado vía id + for — pulsar el texto activa el switch.
  • Cambio se aplica inmediatamente — no esperar a guardar.

Dos & Don'ts

Do

  • Aplica el cambio al instante — switch es para acciones inmediatas.
  • Label describe el resultado positivo ("Activar notificaciones").
  • Usa switch para estados de sistema, checkbox para selección en formulario.

Don't

  • No uses switch cuando el cambio requiere confirmación o un Guardar.
  • No empares switch con texto negativo ("No notificar") — invierte la mental model.
  • No uses switch para opciones múltiples — usa radio-group o checkbox.
