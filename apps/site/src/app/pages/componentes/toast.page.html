Accessibility

  • Uses role="status" with aria-live="polite" — screen readers announce the message without interrupting the user.
  • Action and dismiss buttons have descriptive aria-label attributes.
  • Auto-dismiss timer gives sufficient time (5s default) for the user to read and act.
  • Respects prefers-reduced-motion — entrance animation is disabled.

Dos & Don'ts

Do

  • Keep messages short — one sentence max.
  • Provide an undo action for destructive or hard-to-reverse operations.
  • Auto-dismiss after 5 seconds to avoid stale notifications.
  • Stack multiple toasts if needed (future enhancement).

Don't

  • Don't use for errors that require user action — use a modal or inline alert.
  • Don't show more than one toast at a time (currently single instance).
  • Don't put long multi-line content in the toast pill.
  • Don't set auto-dismiss below 3 seconds — too fast to read.
