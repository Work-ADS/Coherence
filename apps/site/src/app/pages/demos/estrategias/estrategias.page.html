La rentabilidad objetivo indica qué rentabilidad media anual debería obtener el patrimonio financiero del cliente para cubrir los objetivos establecidos. La columna izquierda muestra la rentabilidad media anual que se está considerando en base a la tipología de activos que el cliente posee actualmente.

El máximo gasto anual es un cálculo que permite saber cuál es el máximo gasto que se puede permitir el cliente para cubrir los objetivos establecidos. El gasto es una media anual actualizada.

El gasto previo a retiro supone que el gasto posterior a retiro será el estimado por el usuario ({{ gastoPosteriorLabel() }}).

El gasto posterior a retiro supone que el gasto anterior a retiro es el actual declarado por el usuario ({{ gastoPrevioLabel() }}).

El ingreso anual mínimo se expresa como salario bruto anual mínimo (hasta el momento de retiro o jubilación) necesario para cubrir los objetivos establecidos por el usuario.

La edad de retiro mínima indica cuál es la edad a partir de la que el cliente podría retirarse para cumplir con el resto de sus objetivos.
