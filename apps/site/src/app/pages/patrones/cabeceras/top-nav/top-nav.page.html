El problema

La versión anterior del top bar usaba componentes ad-hoc con estilos inline y no era reutilizable ni testeable. El nuevo Top Nav compone primitivos del Design System (icon-button, inline-edit, status-chip, dropdown-panel, tooltip, toast) para lograr la misma funcionalidad de forma modular y white-label-ready.

Composición

  • Cluster izquierdo: plan-switcher (dual-icon button + dropdown), identity (client name + inline-edit para simId), state chip (interactive + dropdown).
  • Cluster derecho: Notes (icon-button + dropdown-panel), Settings (icon-button + dropdown-panel).
  • Feedback: Toast con undo para todas las acciones mutantes.

Tokens de patrón

El top-nav no define tokens propios — hereda de los tokens de componente de cada primitivo (icon-button, inline-edit, status-chip, dropdown). La superficie es --surface-primary con borde inferior --border-hairline.

Decisiones de interacción

Dual-icon button

Un solo botón con dos iconos SVG (chevron + list) en lugar de dos botones separados. Reduce el noise visual y el target count.

Inline-edit sin modo explícito

El nombre de la planificación se edita in-situ. No hay modal ni formulario separado. Enter/Esc como atajos con toast deshacible.

State chip → dropdown

El chip es un trigger. Click abre un menú con los estados disponibles. Selección cambia inmediatamente (optimistic) + toast con undo.

Acciones derechas = icon-only

Notas y Ajustes son icon-only con tooltip. Los paneles usan dropdown-panel con slots header/body/footer.
