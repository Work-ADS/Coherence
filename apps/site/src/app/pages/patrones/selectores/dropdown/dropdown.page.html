Accessibility

  • aria-haspopup="menu" on the trigger element.
  • aria-expanded reflects open/closed state dynamically.
  • role="menu" on the panel, role="menuitem" on each item.
  • Escape closes and returns focus to the trigger.
  • Arrow keys navigate between items (planned).

Dos & Don'ts

Do

  • Always include a transparent backdrop to handle click-outside dismissal.
  • Use the same animation pattern (opacity + translateY) across all dropdown instances.
  • Group related items with dividers and optional section headings.
  • Keep the panel narrow (260–320px) for action menus; wider for forms/filters.

Don't

  • Don't nest dropdowns inside other dropdowns — use a full panel or dialog instead.
  • Don't use a dropdown for more than 8–10 items — consider a searchable list.
  • Don't omit aria-expanded — screen readers need state changes announced.
  • Don't hardcode pixel sizes — use component tokens for spacing and dimensions.
