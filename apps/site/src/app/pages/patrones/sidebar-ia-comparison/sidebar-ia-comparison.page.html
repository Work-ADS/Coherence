Reglas de la variante

  • El sidebar reacciona a la sección de nivel superior actual.
  • Componentes se divide en Ready + All para mostrar qué está listo.
  • Patrones lista las 9 páginas hijas, incluidas las decisiones.
  • Recursos tiene su propio sub-nav (Descargas, Changelog, Roadmap, FAQ).
} @else if (selectedVariant() === 'pre-may22') {

Reglas de la variante

  • El sidebar es idéntico en todas las páginas — no responde a la sección.
  • Components muestra sólo una selección curada (8 items), no todos los primitivos.
  • Patterns lista 3 items: Sidebar, Headers, Dropdown.
  • No hay sub-navs para Patrones ni Recursos.
} @else {

Reglas de la variante

  • Cuatro secciones siempre visibles a la vez — el usuario ve el alcance completo del sitio.
  • Cabeceras en mayúsculas con icono Lucide distintivo. Funcionan como separador no clicable, no como enlace a la landing.
  • Sin chevrons — las secciones no se colapsan; el sidebar es plano y predecible.
  • Indicador a la derecha sólo cuando otra página relacionada ha cambiado y conviene revisar ésta. Sin indicador = página estable o pendiente (los estados todo siguen en el modelo de datos para automatizaciones futuras, pero la sidebar ya no los anuncia visualmente).
  • Selector de superficie (Blanco / Azul marca / Azul profundo) para validar contraste en cualquiera de los fondos que el DS soporta — blanco flipa con el modo oscuro; los dos azules quedan fijos.
  • Los estados son hardcoded en esta demo (orientativo). Una versión real los leería de un mapa page → status mantenido en el repo.
}

Decisión pendiente

  • May 19 es más fiel al patrón Wise / Linear / Stripe (contexto por sección) y al lock IA de 2026-04-17-rev2 (cada sección tiene su landing + children).
  • Pre-May 22 es más simple de mantener pero pierde la profundidad de Patrones y Recursos. El estado actual del sitio se parece a esto.
  • Una tercera opción combinada: mantener el @switch actual y completar el bloque @default con las 9 entradas de Patrones + un sub-nav de Recursos. Recupera la profundidad sin reescribir la mecánica.
